# План безопасной реализации ColdStore, фаза 1

> Для Hermes: где это практично, следуй строгому TDD и ограничь выполнение модульными тестами, fmt, clippy и проверками компиляции. Не запускай интеграционные тесты и команды, которые обращаются к реальным ленточным устройствам или сервисам хоста.

Цель: сделать репозиторий существенно более настоящим, не подвергая риску окружение хоста. Для этого нужно реализовать сервис метаданных в памяти, функциональный сервис кэша на HDD, более безопасные заглушки без panic для путей, обращающихся к ещё не реализованным внешним сервисам, более подробные проектные документы, а также цели Makefile, которые явно отделяют проверку только модульных тестов от будущей работы по интеграции.

Архитектура:
1. Сервис метаданных становится источником истины для CRUD-операций и переходов между состояниями, которые можно покрыть модульными тестами: состояние хранится в памяти за асинхронными блокировками.
2. Сервис кэша становится полноценным локальным слоем данных/кэша: существующий бэкенд HDD плюс вторичный индекс в памяти для поиска объектов, потоковой передачи, удаления и статистики.
3. Планировщик, ленточный сервис и шлюз сохраняют границы распределённой части без изменений, но там, где это практично, перестают использовать todo!() во внешних вызываемых обработчиках и вместо panic возвращают явные ошибки gRPC, если возможности фазы 2 ещё не реализованы.
4. Проектные документы исправляются так, чтобы безопасно локальную реализацию фазы 1 отличать от распределённой интеграции Raft/ленты фазы 2.

Технологический стек: Rust, Tokio, tonic/prost, serde, timestamps через chrono/prost_types, кэш на HDD поверх файловой системы, только модульные тесты.

Команды проверки (только модульные):
- cargo fmt --all -- --check
- cargo clippy --workspace --all-targets -- -D warnings
- cargo test --workspace --lib --bins
- make unit
- make check-safe

Вне рамок этой сессии:
- Никакой интеграции Raft/OpenRaft
- Никакой интеграции RocksDB
- Никакого доступа к реальным ленточным устройствам
- Никаких сквозных многопроцессных интеграционных тестов
- Никаких изменений окружения хоста за пределами артефактов локальной сборки и тестирования
